モールの応力円

丸棒・薄肉圧力容器の点をなぞる、または微小平板に応力・ひずみを与えると、その点の応力状態がモールの応力円として現れます。荷重の矢印は直接ドラッグできます。

平面応力なので板厚方向（）の垂直応力は 0 ですが、ひずみ は 0 になりません（板厚が変わる）。 も主方向なので、3 つの円は x–y 面・y′–z 面・z–x′ 面（x′・y′ は面内の主応力の方向）になります。紫のゲージ（φ を回すと現れ、0°・45°・90° でロゼットのゲージに重なります）を回して読みが最大・最小になる向きが、応力の主方向（）と一致することも確かめてみてください（等方性材料ではひずみと応力の主方向が同じ）。

内圧などが無いので周方向・半径方向の垂直応力は恒等的に 0 になります。つまり丸棒のこの状態は「軸方向の一軸応力＋ねじりせん断」であり、応力円が原点まわりでどう動くかを見ると、引張だけ・ねじりだけ・その組合せの違いがそのまま読み取れます。
