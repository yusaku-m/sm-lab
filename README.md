# sm-lab — 材料力学の学習プレイグラウンド

材料力学の授業（[Grading](https://github.com/yusaku-m/Grading) リポジトリの採点システム）で
使っている「反力・せん断力・曲げモーメントなどを自動計算するPythonエンジン」を、そのまま
ブラウザで動かして学生に触ってもらうためのツール集。条件（支点・荷重など）を自由に変えると、
その場で再計算され、日本語の解説（計算過程つき）が表示される。

単元（梁・引張圧縮・ねじり・モールの応力円…）が増えても1つのサイトにまとめる方針
（詳しくは「フォルダの中身」参照）。将来 GitHub Pages で公開してTeamsにリンクを貼る想定
（まだ未公開）。

## 3行で

- 中身は本物のPython（sympyで記号計算する`Beam.py`）。JSへの書き換え・簡易版ではない
- でも動いているのはサーバーではなく**学生のブラウザの中**（Pyodideという、Pythonをブラウザで
  動かす仕組みを使っている）
- だからGitHub Pages（静的ファイルしか配れない）でも問題なく公開できる

## なぜこれが成立するのか

「GitHub PagesはPythonを実行できない」というのはよく言われる通り正しいが、それは
**サーバー側でPythonを動かす**（Flaskなどでリクエストのたびに計算する）話。ここでやっているのは
それとは違って、**Python処理系そのものをWebAssemblyという形式にコンパイルして、ブラウザの中で
そのまま動かす**（Pyodideというプロジェクトが作っている）。GitHub Pages側からすると配っているのは
普通のHTML/JS/wasmファイルなので、サーバーサイド実行が要らず問題にならない。

イメージ（「梁」単元の場合）：
```
[学生のブラウザ]
  beam/index.html を開く
   → app.js が画面（支点・荷重の入力欄）を作る
   → worker.js が別スレッドでPyodide（ブラウザ内Python）を起動
      → Beam.py（Gradingから持ってきた本物の計算エンジン）を読み込む
   → 入力が変わるたびに worker.js へ「この配置で計算して」と依頼
   → Beam.py が反力・SFD・BMD・解説文を計算して返す
   → app.js が図と数式（KaTeXという数式表示ライブラリ）を画面に描く
```
サーバーは一切登場しない。GitHub Pagesはただの「ファイル置き場」として使うだけ。

## フォルダの中身

単元が増えても対応できるよう、共通部分とunit（単元）ごとの部分を分けてある。

| ファイル/フォルダ | 役割 |
|---|---|
| `index.html` | トップページ（単元一覧。まだ「梁」しか無いが今後増える） |
| `common/style.css` | 全単元共通のスタイル |
| `py/quiz_web/` | 全単元共通の計算エンジン本体（Gradingから`Beam.py`等をコピーしたもの） |
| `beam/index.html` | 「梁」単元の画面（入力欄・出力欄のHTML） |
| `beam/app.js` | 「梁」単元のUI操作・計算結果の描画 |
| `beam/worker.js` | Pyodideを起動して計算を行う裏方（画面をブロックしないよう別スレッド） |
| `beam/bridge.py` | JS側とPython側の橋渡し役（設定を受け取ってBeam.pyを呼ぶ、梁専用） |
| `mohr/` | 「モールの応力円」単元（3D表示のため構成が違う。下記） |
| `moment/` | 「モーメントのつり合い」単元（材力Ⅰ後期。`mohr/`と同じくPyodide不使用。下記） |

今後「引張圧縮」「ねじり」等を追加するときは、`beam/`と同じ構成
（`index.html`/`app.js`/`worker.js`/`bridge.py`）のフォルダを増やし、トップページから
リンクする形になる予定。

### 「モールの応力円」単元だけ作りが違う

`mohr/`はPyodideを使っていない（`worker.js`/`bridge.py`が無い）。丸棒に軸力・曲げ・ねじりを
加えたときの応力は短い式で書けてsympyが要らない一方、「矢印をドラッグしながら色分布が
ぬるぬる追従する」という作りにしたかったため、計算はすべてJavaScript側（`mohr/stress.js`）に
置いてある。3Dの描画はthree.js（CDN読み込み）、モールの円はSVGで描いている。

| ファイル | 役割 |
|---|---|
| `mohr/index.html` | 画面 |
| `mohr/style.css` | この単元だけの見た目（`common/style.css`は使わない） |
| `mohr/stress.js` | 応力の計算（断面諸量・主応力・回転の式・カラーマップ） |
| `mohr/rod3d.js` | 丸棒の3D表示（コンター・荷重の矢印・ドラッグ・点の拾い上げ） |
| `mohr/mohr2d.js` | モールの応力円と、回転させた応力要素の図 |
| `mohr/app.js` | 入力欄と上記3つの配線 |

### 「モーメントのつり合い」単元

材力Ⅰ後期の最初（Grading の `2026/2nd/week1.py`、O点まわりのモーメント）に合わせた単元。
計算は「距離×力の鉛直成分」の足し算だけなのでsympyは使わず、式の表記（$rac{5}{12}L$、
$\cosrac{\pi}{6}$ など）も JS 側で組み立てている。図はSVG、記号はKaTeX。

| ファイル | 役割 |
|---|---|
| `moment/index.html` | 画面 |
| `moment/style.css` | 見た目（`mohr/style.css`と同じテーマ） |
| `moment/model.js` | モーメント・合力の計算、吸着、式（TeX）の組み立て。荷重の種類の登録簿 `ACTION_TYPES` |
| `moment/figure.js` | 棒・荷重・円弧の矢印の描画と、ドラッグ操作 |
| `moment/app.js` | 状態・荷重の一覧・式の表示・アニメーション・URL共有 |

## 今できること（梁: Phase 1）

- 支点（ピン・ローラー・固定）と荷重（集中荷重・集中モーメント・分布荷重）を自由に追加・削除・編集
- 梁の構成図、反力とその計算過程の解説、SFD、BMDを表示

## 今できること（モーメントのつり合い）

- 棒に集中荷重を好きな数・位置・大きさ・向きで置く（図の上で直接ドラッグ、または一覧に入力）
  - 矢印の先端を上下に引くと大きさと上下の向き。左右に大きく引くと斜め（π/6・π/4・π/3・π/2 に吸着、
    それ以外は1°刻み）
  - 作用点と回転中心 O は L/2・L/3・L/4・L/5・L/10 の位置に吸着（それ以外は L/200 刻み）
- O まわりのモーメントを**荷重ごとの円弧の矢印**（長さ＝大きさ、向き＝回す向き）と合計 $M_O$ で表示
- 式は「L の分数で書く（O からの距離）」と「x 座標で書く（$x_i-x_O$）」を切り替え
- 支え方は「O で回転だけ許して支える」（資料と同じく O が丸く膨らんだ図）と「自由体」を切り替え。
  自由体では $F_x, F_y$ も出し、偶力なら O を動かしても $M_O$ が変わらないことを確かめられる
- 「動かしてみる」で、動き始めの加速度のまま棒が回り出す（自由体は重心まわりの回転＋並進）
- 設定は URL（とQRコード）で共有
- 分布荷重・集中モーメントは未対応（`model.js` の `ACTION_TYPES` に足せるようにしてある）

## 今できること（モールの応力円）

- 丸棒に **引張／圧縮 P・両端の曲げモーメント M・ねじりモーメント T** を加える
  （スライダー・数値入力・3D図の矢印を直接ドラッグ、のどれでも）
- 棒の表面と断面に応力のコンターを表示（σx 軸方向・σy 周方向・σr 半径方向・τxy せん断・
  σ1 最大主応力・τmax 最大せん断応力・σeq 相当応力 から選択）
  ※ 座標の呼び方は講義資料に合わせて x=軸方向・y=周方向・r=半径方向。
  曲げは図に描いた向き（棒の右端に右ねじ正の偶力）に対応する分布で、M>0 なら棒の下側が引張
- 棒の一部を輪切りに抜いて断面を見せる。輪切りの位置は軸に沿ってドラッグして移動
- 棒の上をドラッグすると、その点の**モールの応力円**（既定は x–y 面、チェックボックスで
  残り2面も）と、角度 φ だけ回した面に働く応力（応力要素の図つき）が同時に更新される
- 探触点には x（軸方向）・y（周方向）・r（半径方向）の矢印と記号ラベルが出る
- 「単純引張」「単純曲げ」「単純ねじり」ボタンで、残り2つの荷重を 0 にできる
- 「応力円が最大の点へ」ボタンで、いちばん大きな応力円になる点を自動で選べる
- 面を φ だけ回したときの応力円上の動きは、φ=0 の直径を点線で残して 2φ の円弧で示す。
  縦軸 τ は下向きが正（面を回した向きと円上の点の動く向きが揃うようにするため）。
  **円の直径は掴んでそのまま回せる**（PC。スマホはスライダー）
- **応力円の軸範囲を固定できる**（自動／固定）。固定すると荷重を変えても目盛りが動かないので、
  荷重の符号が変わるときや大きさが変わるときに円がどう動くかをそのまま見せられる。
  範囲外へ出た円は切り取って表示。スマホでは設定UIは出ないが、共有URLの値は効く
- **いまの設定はそのまま URL になる**（アドレスバーが常に現在の設定を指す）。
  ページ最下部の「現状QR」ボタンから URL のコピーと QR コードが出せるので、
  スライドに貼ったり授業中に学生へ配ったりできる
- PC（左に棒・右に応力円）でもスマホでも使える。スマホでは**応力円・応力要素の図・
  回転スライダー・コンター図が1画面に収まる**ように、面の選択トグルと成分表を省略し
  （数値は応力円の中に書いてある）、丸棒パネルに「単純引張」「単純ねじり」
  「応力円が最大の点へ」を出している

## まだできないこと（梁: Phase 2で追加予定）

- たわみ・たわみ角の表示
- 曲げ応力分布・断面係数の表示
- 断面形状（矩形・円形など）や材料を選ぶUI（今は矩形・軟鋼で固定）

## 手元で試す方法

```
cd sm-lab
python -m http.server 8000
```
その後ブラウザで `http://localhost:8000` を開く（トップページ）。「梁」または
「モールの応力円」をクリックするか、直接 `http://localhost:8000/beam/index.html` /
`http://localhost:8000/mohr/index.html` を開く。
（`index.html` をダブルクリックして直接開く方法は動かない。ブラウザのセキュリティ制限で、
Pyodideが必要なファイルを`file://`からは読み込めないため、必ず上記のように簡易サーバー経由で開く）
